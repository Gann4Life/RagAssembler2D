# Tools: Hinge Joint

**Hinge Joint.** Behavior: [`DESIGN.md` §5.5](../design/05-5-tools.md#55-tools) (Hinge Joint) and [§2.4](../design/02-object-model.md#24-joints). One core module, `js/tools/hinge.js`; it does not use `dragShapeTool` (different draft, refusal at press, cursor feedback), but follows the same press lifecycle.

```
js/tools/hinge.js
  hingeTool() → Tool
  hingePair(model, hits: number[]) → { bodyA, bodyB } | null     body uids, ordered; null = refused
  hingeLimit(distance: number, shift: boolean) → number           θ in rad, distance in CSS px
```

- **`hingePair(model, hits)`:** walks `hits` (uids, topmost first, as `ctx.hitTest` returns them), skips every uid whose node is not a `shape`, maps each shape to its body (`model.get(uid).parent`), and takes the first two distinct bodies. `null` when fewer than two are found or `jointBetween(model, p, q)` is not `null`; else `orderJointBodies(model, p, q)` ([Joint graph](joint-graph.md#joint-graph)).
- **`hingeLimit(distance, shift)`:** `deg = min(180, round(distance))` for the distance in CSS px (1 px = 1°), then `snapAngle(deg · π / 180, shift)` from `js/viewport/snap.js` (15° steps with SHIFT; 180° is a multiple, so the clamp holds). Returns radians, never `-0`. Examples: 0 → 0; 37.4 → 37°; 37.6 → 38°; 250 → 180°; 37 with SHIFT → 30°; 38 with SHIFT → 45°.
- **`hingeTool()`** calls `defineTool({ id: 'hinge', cursor: 'crosshair', hover: false, … })`; its state (`ctx`, `press`) lives in the closure.
  - `activate(ctx)` keeps `ctx`; `deactivate()` drops the press.
  - `pointerDown`, button 0: `pair = hingePair(ctx.model, ctx.hitTest(e.screen))`. A `null` pair opens no press (refused: the registry's empty gesture records nothing). Otherwise `anchor = ctx.snapPoint(e.world)` (world m), the `bodyB` world transform from `placement(ctx.model).bodies` (the tool only runs in Edit mode, where the rest pose is the displayed pose), `zero = jointZeroAngle(anchor, bodyBTransform)` (`js/viewport/placement.js`), and `press = { screen: e.screen, anchor, pair, zero, dragging: false, last: e }`; `ctx.setCursor(null)`; overlay invalidated. Button 2 is ignored.
  - `pointerMove` without a press (hover moves, and moves after a refused press): `ctx.setCursor(hingePair(ctx.model, ctx.hitTest(e.screen)) ? null : 'not-allowed')`; nothing is drawn. With a press: stores `last = e`, latches `dragging` once `hypot(e.screen − press.screen) ≥ DRAG_THRESHOLD` (never unlatches), invalidates the overlay.
  - **θ** of an event: `0` while not dragging; else `hingeLimit(hypot(e.screen − ctx.camera.worldToScreen(press.anchor)), e.shift)`. Reading the anchor's screen position at each event keeps θ right after a pan or zoom; modifier changes and pans reach the tool as re-sent moves ([Input routing](tools.md#tools)).
  - `pointerUp`, button 0, of the press: latch with `e`, take θ of `e`, clear the press, invalidate the overlay, then `uid = ctx.history.execute(createJoint({ ...press.pair, anchor: ctx.toLocal(press.anchor), limits }))` with `limits` left out when θ = 0 (a pin: the schema default, disabled) and `{ enabled: true, lower: −θ, upper: θ }` otherwise; then `ctx.selection.set([uid])`. One undo step through the registry's gesture; a throw is handled by the registry (cancel, rethrow).
  - `cancel()` drops an open press, invalidates the overlay and returns `true`; with no press it returns `false` (so Esc then clears the selection). `keyDown` consumes nothing.
  - `drawOverlay(g)` with a press, in screen px: `a = ctx.camera.worldToScreen(press.anchor)`, `g.circle(a.x, a.y, GIZMO_SIZE.jointCircle)`, the needle `g.moveTo(a.x, a.y)`, `g.lineTo(a.x + cos(zero) · GIZMO_SIZE.jointNeedle, a.y − sin(zero) · GIZMO_SIZE.jointNeedle)` and, when θ of `last` is above 0, the arc the way `js/viewport/gizmos.js` draws limits: `g.moveTo` to the point at angle `zero − θ` and radius `GIZMO_SIZE.jointArc`, then `g.arc(a.x, a.y, GIZMO_SIZE.jointArc, −(zero − θ), −(zero + θ), true)`; then one `g.stroke({ width: LINE_WIDTH.outline, color: COLORS.highlight })`. No fill. Without a press nothing is drawn. Only these five `PIXI.Graphics` methods are used. Since `zero` comes from `jointZeroAngle` on world values, the preview matches the gizmo the created joint gets.
- **Imports:** `js/tools/tool.js` (`defineTool`, `DRAG_THRESHOLD`), `js/commands/create.js` (`createJoint`), `js/model/queries.js` (`jointBetween`, `orderJointBodies`), `js/viewport/placement.js` (`placement`, `jointZeroAngle`), `js/viewport/snap.js` (`snapAngle`), `js/viewport/style.js` (`COLORS`, `GIZMO_SIZE`, `LINE_WIDTH`); all core.
- **Composition:** `js/editor.js` imports `hingeTool` and adds `hingeTool()` to `TOOLS`. The `tool:hinge` action, the `H` hotkey and the toolbar button then enable through the existing rules (Edit mode only, `tool.hinge`); nothing else changes.
