# Tools: Hinge Joint

**Hinge Joint.** Behavior: [`DESIGN.md` §5.5](../design/05-5-tools.md#55-tools) (Hinge Joint) and [§2.4](../design/02-object-model.md#24-joints). One core module, `js/tools/hinge.js`; it does not use `dragShapeTool` (different draft, refusal at press, cursor feedback), but follows the same press lifecycle.

```
js/tools/hinge.js
  hingeTool() → Tool
  hingePair(model, hits: number[]) → { bodyA, bodyB } | null     body uids, ordered; null = refused
  hingeLimits(phi: number, { shift, alt }) → { lower, upper }       rad; #152 replaces hingeLimit(distance, shift)
```

**#152** makes the drag one-sided ([`DESIGN.md` §5.5](../design/05-5-tools.md#55-tools), Hinge Joint, Drag) and adds a readout; `hingeLimit` is removed. The bullets below describe the #152 behavior; the press, pair, refusal, cursor and composition rules are unchanged from #16.

- **`hingePair(model, hits)`:** walks `hits` (uids, topmost first, as `ctx.hitTest` returns them), skips every uid whose node is not a `shape`, maps each shape to its body (`model.get(uid).parent`), and takes the first two distinct bodies. `null` when fewer than two are found or `jointBetween(model, p, q)` is not `null`; else `orderJointBodies(model, p, q)` ([Joint graph](joint-graph.md#joint-graph)).
- **`hingeLimits(phi, { shift, alt })`:** `phi` in (−π, π]; `a = snapAngle(round(phi · 180 / π) · π / 180, shift)` (`js/viewport/snap.js`; ±180° are multiples of 15°). With `alt`: `{ lower: −|a|, upper: |a| }`; else `a > 0` → `{ lower: 0, upper: a }`, `a < 0` → `{ lower: a, upper: 0 }`, `a = 0` → `{ lower: 0, upper: 0 }`. Never `-0`. Examples (degrees in, radians out): 37.4 → 0 / 37°; −37.6 → −38° / 0; 37 with SHIFT → 0 / 30°; −38 with SHIFT → −45° / 0; 45 with ALT → −45° / 45°; 0.4 → 0 / 0; 180 → 0 / 180°.
- **`hingeTool()`** calls `defineTool({ id: 'hinge', cursor: 'crosshair', hover: false, … })`; its state (`ctx`, `press`) lives in the closure.
  - `activate(ctx)` keeps `ctx`; `deactivate()` drops the press.
  - `pointerDown`, button 0: `pair = hingePair(ctx.model, ctx.hitTest(e.screen))`. A `null` pair opens no press (refused: the registry's empty gesture records nothing). Otherwise `anchor = ctx.snapPoint(e.world)` (world m), `zero = placement(ctx.model).root.angle` (the root's +X, the rest zero direction every joint gets; the tool only runs in Edit mode, where the rest pose is the displayed pose), and `press = { screen: e.screen, anchor, pair, zero, dragging: false, last: e }`; `ctx.setCursor(null)`; overlay invalidated. Button 2 is ignored.
  - `pointerMove` without a press (hover moves, and moves after a refused press): `ctx.setCursor(hingePair(ctx.model, ctx.hitTest(e.screen)) ? null : 'not-allowed')`; nothing is drawn. With a press: stores `last = e`, latches `dragging` once `hypot(e.screen − press.screen) ≥ DRAG_THRESHOLD` (never unlatches), invalidates the overlay.
  - **φ** of an event: `0` while not dragging; else, with `d = e.screen − ctx.camera.worldToScreen(press.anchor)`, the previous φ when `hypot(d) < 1` CSS px, otherwise `wrap(atan2(−d.y, d.x) − press.zero)` to (−π, π] (the camera has no rotation, so the screen direction with Y flipped is the world direction). The press keeps the last φ (`press.phi`, initially 0). **Limits** of an event: `hingeLimits(φ, { shift: e.shift, alt: e.alt })`. Reading the anchor's screen position at each event keeps φ right after a pan or zoom; modifier changes and pans reach the tool as re-sent moves ([Input routing](tools.md#tools)).
  - `pointerUp`, button 0, of the press: latch with `e`, take the limits of `e`, clear the press, invalidate the overlay, then `uid = ctx.history.execute(createJoint({ ...press.pair, anchor: ctx.toLocal(press.anchor), limits }))` with `limits` left out when both are 0 (a pin: the schema default, disabled) and `{ enabled: true, lower, upper }` otherwise; then `ctx.selection.set([uid])`.
  - `readout()`: while a latched press exists, `{ text: formatLimits(lower, upper), screen: last.screen + (16, 16) }` (`js/tools/joint-limits.js`); else `null`. One undo step through the registry's gesture; a throw is handled by the registry (cancel, rethrow).
  - `cancel()` drops an open press, invalidates the overlay and returns `true`; with no press it returns `false` (so Esc then clears the selection). `keyDown` consumes nothing.
  - `drawOverlay(g)` with a press, in screen px: `a = ctx.camera.worldToScreen(press.anchor)`, `g.circle(a.x, a.y, GIZMO_SIZE.jointCircle)`, the needle `g.moveTo(a.x, a.y)`, `g.lineTo(a.x + cos(zero) · GIZMO_SIZE.jointNeedle, a.y − sin(zero) · GIZMO_SIZE.jointNeedle)` and, when the limits of `last` are not both 0, the arc the way `js/viewport/gizmos.js` draws limits: `g.moveTo` to the point at angle `zero + lower` and radius `GIZMO_SIZE.jointArc`, then `g.arc(a.x, a.y, GIZMO_SIZE.jointArc, −(zero + lower), −(zero + upper), true)`; then one `g.stroke({ width: LINE_WIDTH.outline, color: COLORS.highlight })`. No fill. Without a press nothing is drawn. Only these five `PIXI.Graphics` methods are used. Since `zero` is the same root +X that `placement` gives the created joint at rest, the preview matches its gizmo.
- **Imports:** `js/tools/tool.js` (`defineTool`, `DRAG_THRESHOLD`), `js/commands/create.js` (`createJoint`), `js/model/queries.js` (`jointBetween`, `orderJointBodies`), `js/viewport/placement.js` (`placement`), `js/viewport/snap.js` (`snapAngle`), `js/viewport/style.js` (`COLORS`, `GIZMO_SIZE`, `LINE_WIDTH`), and since #152 `js/tools/joint-limits.js` (`formatLimits`); all core.
- **Tests (#152):** in `tests/hinge-tool.test.js`, the `hingeLimit` table is replaced by the `hingeLimits` table above (each sign, SHIFT, ALT with both signs, ±180°, no `-0`); a drag counter-clockwise of the zero direction creates `0 / φ`, clockwise `φ / 0`, with ALT `±|φ|`; φ measured against a rotated root; φ measured from the root's +X when bodyB lies elsewhere (straight up → `0 / 90°`, straight down → `−90° / 0`); the needle along the root's +X; the pointer back within 1 px of the anchor keeps the last φ; a drag that ends on the zero direction creates a pin; ALT and SHIFT pressed and released mid-drag (re-sent moves); the pan case now checks φ; `readout()` text and position during a drag, `null` before the latch and after the release; `drawOverlay` draws the arc from `lower` to `upper`. Every other #16 case is kept.
- **Composition:** `js/editor.js` imports `hingeTool` and adds `hingeTool()` to `TOOLS`. The `tool:hinge` action, the `H` hotkey and the toolbar button then enable through the existing rules (Edit mode only, `tool.hinge`); nothing else changes.
