# Tools: Circle and Box

**Circle and Box.** Behavior: [`DESIGN.md` §5.5](../design/05-5-tools.md#55-tools) (Circle and Box). Three core modules under `js/tools/`:

```
js/tools/drag-shape.js   dragShapeTool({ id, click, drag }) → Tool      shared press-drag-release lifecycle
  click(anchor: Vec2) → ShapeDraft                                      default-size draft at the anchor
  drag(anchor: Vec2, e: ToolPointerEvent, ctx: ToolContext) → ShapeDraft | null   null = refused (a size of 0)
  ShapeDraft { center: Vec2 (world m), shape: { type: 'circle', radius } | { type: 'box', width, height } }
                                                                        world-axis-aligned, sizes in m
js/tools/circle.js       circleTool() → Tool, circleDraft(anchor, pointer, snapLength) → ShapeDraft | null
js/tools/box.js          boxTool() → Tool, boxDraft(anchor, pointer, { shift, ctrl, alt }) → ShapeDraft | null
```

- **`dragShapeTool`** calls `defineTool` with `cursor: 'crosshair'`, `hover: false` and these handlers; its press state lives in the closure, so each factory call is independent.
  - `activate(ctx)` keeps `ctx`; `deactivate()` drops the press.
  - `pointerDown`, button 0: the press is `{ screen: e.screen, anchor: ctx.snapPoint(e.world), dragging: false, last: e }`; the overlay is invalidated. Button 2 and moves without a press are ignored (no hover work).
  - `pointerMove` during the press stores `last = e` and latches `dragging` once `hypot(e.screen − press.screen) ≥ DRAG_THRESHOLD`; it never unlatches. Then it invalidates the overlay. Modifier changes and pans reach it as re-sent moves ([Input routing](tools.md#tools)).
  - `pointerUp`, button 0, of the press: applies the same latch to `e`, clears the press, invalidates the overlay, and computes the draft: `click(press.anchor)` when not dragging, else `drag(press.anchor, e, ctx)`. A `null` draft executes nothing. Otherwise `uid = ctx.history.execute(createShapeBody({ position: ctx.toLocal(center), angle: −rootAngle, shape }))`, with `rootAngle` = `ctx.model.prop(ROOT_UID, 'angle') ?? 0` (the registry's rule), then `ctx.selection.set([uid])`. The registry's open gesture makes it one undo step; a throw is handled by the registry (cancel, rethrow).
  - `cancel()` drops an open press, invalidates the overlay and returns `true`; with no press it returns `false`. `keyDown` consumes nothing (the default).
  - `drawOverlay(g)` with a press: the draft of the latest event (`click` while not dragging, else `drag` with `last`), in screen px through `ctx.camera.worldToScreen` and `ctx.camera.scale`: a circle with `g.circle(x, y, r)`, a box with `g.rect(x, y, w, h)` from its screen top-left corner (the camera does not rotate, so a world-axis-aligned box stays axis-aligned), then `g.fill({ color: COLORS.highlight, alpha: 0.2 })` and `g.stroke({ width: LINE_WIDTH.outline, color: COLORS.highlight })` from `js/viewport/style.js`. A `null` draft and no press draw nothing. Only these four `PIXI.Graphics` methods are used, so tests record them with a fake.
- **`circleDraft(anchor, pointer, snapLength)`:** `radius = snapLength(hypot(pointer − anchor))` with the raw (unsnapped) `pointer`, `center = anchor`; `null` when the radius is 0. `circleTool` passes `e.world` and `ctx.snapLength`; its `click` gives radius `defaultsOf('shape', 'circle').shape.radius`.
- **`boxDraft(anchor, pointer, { shift, ctrl, alt })`:** the rule and example of [`DESIGN.md` §5.5](../design/05-5-tools.md#55-tools), with `pointer` already snapped; `null` when a size is 0. `boxTool` passes `ctx.snapPoint(e.world)` and the event's modifiers; its `click` gives `defaultsOf('shape', 'box').shape.width` × `height`. Defaults are read from `lib/schema.js`, never redeclared.
- **Composition:** `js/editor.js` imports `circleTool` and `boxTool` and adds `circleTool()` and `boxTool()` to the tool list it passes to `new ToolRegistry` (list order does not matter; the registry orders by `TOOL_SPECS`). `tool:circle` and `tool:box` actions, the `C`/`R` hotkeys and the toolbar buttons then enable through the existing rules; nothing else changes.
