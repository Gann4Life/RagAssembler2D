| `lib/geometry.js` | Pure 2D math in meters/radians. Built so far: transforms and shape bounds (#11), inverse transform, hit testing and mass (#12), `shapeGeometryValid` (#13); #20 and #25 add the rest (planned row below). `shapeBounds` throws `TypeError` for an unknown shape type or a polygon with no vertices, and may return non-finite bounds for malformed numbers. `pointInShape` never throws: invalid geometry (unknown type, non-positive size, fewer than 3 vertices, non-finite numbers), a non-finite transform or point give `false`; polygons use the even-odd rule, so concave and clockwise drafts are hit as drawn; a negative or non-finite `tolerance` counts as 0. `shapeMass` follows Box2D's rule (area × density; circle and box centers, polygon centroid) with the absolute polygon area, so a clockwise polygon has the same mass as its counter-clockwise twin and a concave draft gets its own area (Box2D would use the convex hull; concave polygons are validation errors, #25); invalid geometry, zero area, or a negative or non-finite density give mass 0 and center `null`. `bodyMass` sums the shapes with mass above 0 (sensors included). | `transformPoint(t, p)`, `composeTransforms(parent, child)`, `invertTransform(t)`, `shapeBounds(shape, t) → Aabb` (the `shape` record in body-local meters under transform `t`), `shapeGeometryValid(shape) → boolean` (the validity rule `pointInShape` applies), `pointInShape(shape, t, p, tolerance = 0) → boolean` (`tolerance` in meters), `shapeMass(shape, density) → { mass, center: Vec2 \| null }`, `bodyMass(fixtures) → { mass, center: Vec2 \| null }` (`fixtures`: iterable of `{ shape, density }`; body-local, `center` `null` when the mass is 0), typedefs `Vec2` (`x`, `y`), `Transform` (`x`, `y`, `angle`), `Aabb` (`minX`, `minY`, `maxX`, `maxY`) | — |
| `lib/geometry.js` (`bodyMassData`) | `bodyMassData(fixtures) → { mass, center: Vec2 \| null, inertia }`: `bodyMass` plus the rotational inertia about the center of mass (kg·m², Box2D's per-shape rule, parallel-axis sum; 0 when the mass is 0). | `lib/motor.js` | Suggested torques ([`DESIGN.md` §3.1, §3.2](../design/03-physics-drive-model.md#31-suggested-motor-torque)): per joint, splits the joint graph at the joint, sums mass and inertia per side about the anchor and the straightened reach of each side; for the balance, the inertia of the connected set about its center plus the off-root weight term. Pure, never throws. Used by the editor's automatic motor torque (`js/model/motor-torque.js`) and Hinge tool, by `lib/validate.js` (`W_MOTOR_OVERPOWERED`, `W_MOTOR_UNDERPOWERED`) and by `lib/migrate.js` (1 → 2); RagImporter's runtime does not call it. | `motorTorqueSuggestions(doc) → Map<jointId, number \| null>` (`doc`: `{ bodies, joints }` in file shape), `balanceTorqueSuggestion(doc) → number \| null`, `MOTOR_TORQUE` (frozen `{ alpha: 100, gravity: 10, min: 0.001, overpoweredFactor: 1000, margin: 2 }`) | `lib/geometry.js` (`bodyMassData`, `transformPoint`) |
| `lib/migrate.js` | Migrates an older format version to the latest through an ordered chain of pure steps ([`DESIGN.md` §6.3](../design/06-file-format.md#63-versioning)). Applies, while one exists, the step whose `from` equals the document's `version`, setting `version` to its `to`; returns the input object itself when no step applies (current version, newer or unknown version, not an object, wrong `format`), so `validate`'s gate reports those. Never mutates its input. Throws `TypeError` only for a malformed chain. `MIGRATIONS` holds 1 → 2 (adds `ragdoll.balance`, `enabled: true`, `maxTorque` = `balanceTorqueSuggestion` or 80, gain 10, damping 0.5, maxSpeed 20); a test asserts its last step has `to === FORMAT_VERSION`. Used by the editor loader only. | `migrate(json, chain = MIGRATIONS) → { json, notes }`, `MIGRATIONS` (frozen), typedef `MigrationStep` | `lib/schema.js` (`FORMAT`), `lib/motor.js` (`balanceTorqueSuggestion`) |
| `lib/evaluate.js` | Pure animation evaluator ([`DESIGN.md` §4.3–4.4](../design/04-animation-model.md#43-keys-and-interpolation), [§5.1](../design/05-1-modes.md#51-editor-modes) FK): track sampling (looping clips interpolate last key → first key across the wrap), channel defaults, clip sampling, channel resolution with root and runtime multipliers, the FK pose (`rootBody` turned about its rest center of mass) and its inverse for one joint. The joint limit rule (#195): `clampToLimits` returns `angle` unchanged unless `limits.enabled === true` with finite `lower` and `upper`; a key is outside when `Math.abs(clampToLimits(v, limits) - v) > LIMIT_TOLERANCE`. | `sampleTrack(keys, t, discrete = false, loopLength = null)`, `channelDefault(targetType, channel, base)`, `evaluateClip(clip, time)`, `resolveChannels(def, layers, runtime = {})`, `fkPose(def, joints, bodyAngle = 0) → Map<bodyId, Transform>`, `jointAngleForBody(def, jointId, bodyAngle, pose) → number \| null`, typedefs (`Key`, `JointPose`, …), `LIMIT_TOLERANCE` (1e-5 rad), `clampToLimits(angle, limits) → number` | `lib/schema.js` (`CHANNELS`), `lib/geometry.js` (`bodyMassData`, `invertTransform`, `transformPoint`) |
