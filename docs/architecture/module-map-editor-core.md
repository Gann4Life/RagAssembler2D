# Module map: editor core

| Module | Responsibility | Public exports | Imports |
|---|---|---|---|
| `index.html` | Editor page: loads `css/editor.css`, the vendored libraries as classic scripts and `js/main.js` as the only module; holds the header placeholder and the viewport panel markup. | none | — |
| `css/editor.css` | Editor styles: dark theme variables, full-height grid layout, header toolbar (no wrapping, horizontal scroll, Workspace group pushed right), muted disabled buttons, scrolling workspace, dock (absolutely positioned stacks, tab bars, gutters with grips, drop preview, drag ghost, drag and resize cursors), tab bar edge fades (12 px) and insertion caret, Timeline fold button, resize grips shown on hover and drag, popup menu, viewport host cursor `var(--tool-cursor, default)` (the tool cursor set by `js/viewport.js`; the inline `grab`/`grabbing` cursor of navigation wins over it), viewport focus ring drawn above the canvas, popover and Settings popover (groups, rows, read-only and `aria-invalid` fields), the Hierarchy panel (toolbar, tree rows, marks, badges; [Hierarchy and deletion](hierarchy-and-deletion.md#hierarchy-and-deletion)), the `--error` (`#e5484d`) and `--warning` (`#f5a524`) tokens, `.visually-hidden`. | none | — |
| `js/main.js` | Editor bootstrap ([Editor boot](editor-boot.md#editor-boot)): checks the `PIXI` and `Box2D` globals, restores and saves the editor settings, creates the editor (with `confirm: (request) => confirmDialog(document, request)`, #124), mounts the header, creates the dock, registers the DOM actions (`window`, `panel:<id>`, `reset-layout`, `settings`, `frame-selection`, `frame-all`), passes the Settings popover its `document` adapter and keeps it refreshed, keeps the header buttons in sync with the actions, routes header clicks and document `keydown` events (with `editor.tools`) to the actions, and creates the viewport with the selection, modes and tool registry. #145 calls `RagImporter.configure({ Box2D, PIXI })` at boot and passes `physics: { startPose }`, backed by `createPoseSession(Box2D, …)`, to `createEditor`. | none | any `js/` |
| `js/editor.js` | Core. Composition root without DOM ([Editor composition](editor-composition.md#editor-composition)): builds model, history, selection, modes, camera, the tool registry (first `mode` listener, so it owns cancellation on mode changes) and actions, registers `undo`, `redo`, `escape` (`if (!tools.cancel()) selection.clear()`), one `tool:<id>` action per registered tool and `delete`, `add-shape`, `add-joint` and `new` ([Hierarchy and deletion](hierarchy-and-deletion.md#hierarchy-and-deletion)): `delete` runs `deleteObjects` on the object selection, first awaiting the `confirm` option when the plan removes tracks (#124), `add-shape` and `add-joint` create a default box body or an unassigned joint at the origin and select it; all three need `edit.rest` and no open gesture. The registered tools are the private `TOOLS` list of factories: `selectTool`, `selectBoxTool`, `circleTool`, `boxTool`, `hingeTool`. It also registers `pivot-mode`, which toggles `gizmo.pivot` between `center` and `last` in every mode and is disabled during a gesture. The `TOOLS` list is [select, select-box, circle, box, hinge, pose]. #145: `createEditor({ settings, physics })` passes `physics` to the registry and registers `poseTool`. | `createEditor({ settings?, physics?, confirm?, editorVersion? } = {}) → Editor` (throws `TypeError` when `settings` is given and is not a `Settings`, or `confirm` or `editorVersion` is given and is not a function), typedefs `ConfirmRequest`, `Editor` (`model`, `history`, `selection`, `modes`, `actions`, `settings`, `camera`, `tools`, `editorVersion`) | `lib/schema.js` (`defaultsOf`), `js/model/model.js` (`ROOT_UID`), `js/model/selection.js`, `js/commands/history.js`, `js/commands/create.js`, `js/commands/delete.js`, `js/model/io.js` (`newDocument`), `js/version.js` (`DEV_VERSION`), `js/modes.js`, `js/actions.js`, `js/settings.js`, `js/viewport/camera.js`, `js/tools/registry.js`; `js/tools/select.js`, `js/tools/select-box.js`, `js/tools/circle.js`, `js/tools/box.js`, `js/tools/hinge.js`, `js/tools/pose.js`; later the other tool modules (#15, #38) |
| `js/settings.js` | Core. Editor settings store ([`DESIGN.md` §5.3](../design/05-3-header.md#53-header)): keys `grid.visible`, `grid.size` (m), `grid.subdivisions`, `snap.grid`, `display.mode` (`'shapes' \| 'sprites' \| 'both'`), `overlay.names`, `overlay.centers`, `overlay.contacts` (booleans, default `false`; #12) and `gizmo.pivot` (`'center'` or `'last'`, default `'center'`; #128) with defaults and ranges; `set` throws `Error` for an unknown key and `RangeError` for an invalid value, and emits `settings` only when the value changes. `toJSON` nests by key prefix: `{ version, grid: { visible, size, subdivisions }, snap: { grid }, display: { mode }, overlay: { names, centers, contacts }, gizmo: { pivot } }`. `restore` reads such a record field by field: missing fields take their default (a record stored before #12 restores the overlays off, and one stored before #128 restores `gizmo.pivot` as `center`, without warnings), invalid ones too with a warning; a record that is not an object, or whose `version` is missing or not `SETTINGS_VERSION`, is ignored as a whole with one warning (no migration yet); `undefined` gives the defaults without warnings. No storage access and no `pixelsPerMeter` (document data). Not undoable. | `Settings` (`get(key)`, `set(key, value)`, `toJSON() → { version, … }`, `on/off('settings')`, static `restore(record) → { settings, warnings }`), `SETTINGS_VERSION` (1), `SETTING_SPECS`, typedef `SettingKey` | `lib/emitter.js` |
| `js/units.js` | Core. UI conversions: m ⇄ px, rad ⇄ deg, mult ⇄ %; other units unchanged ([schema.md](../schema.md)). The only place UI units exist. Converts single numbers only; callers convert `vec2` fields per component. `m` needs a finite `pixelsPerMeter` above 0, else `RangeError`. Later issues (#20) add only what they need. | `toDisplay(value, unit, pixelsPerMeter)`, `fromDisplay(value, unit, pixelsPerMeter)`, `displayUnit(unit) → 'px' \| '°' \| '%' \| unit` | — |
| `js/viewport/camera.js` | Core. Camera ([Viewport camera, grid and snapping](viewport-camera-grid-snapping.md#viewport-camera-grid-and-snapping)): `center` (m), `scale` (CSS px/m, clamped), viewport size, world ⇄ screen with the Y flip, pan, zoom about a screen point, framing a box into insets, visible world box. Independent of `pixelsPerMeter`. Starts at `center` (0, 0), `scale` 32 px/m and size 0 × 0; the viewport frames everything on start, so these only matter before the first `setSize`. Non-finite arguments throw `RangeError`. Emits `camera`. | `Camera` (`center`, `scale`, `width`, `height`, `setSize(w, h)`, `worldToScreen(p)`, `screenToWorld(p)`, `panBy(dx, dy)`, `zoomAt(screenPoint, factor)`, `frame(aabb, insets?)`, `visibleBounds() → Aabb`, `on/off('camera')`), `MIN_SCALE` (2), `MAX_SCALE` (10000), `MAX_CENTER` (10000), `KEY_ZOOM_STEP` (√2), `wheelZoomFactor(deltaY, deltaMode, ctrlKey, viewportHeight)`, typedef `Insets` (`top`, `right`, `bottom`, `left`, px) | `lib/emitter.js` |
| `js/viewport/bounds.js` | Core. Framing box ([`DESIGN.md` §5.4](../design/05-4-viewport.md#54-viewport)): world bounding box of the shapes (through `shapeBounds`), joint anchors and root position, of everything or of the given uids, under the root transform and an optional pose; grown to the minimum framing size. The framing insets keep 16 px around the box and add the Tools overlay width on the left ([`DESIGN.md` §5.4](../design/05-4-viewport.md#54-viewport)). Bodies missing from the pose use their rest transform. A joint anchor (root-local) follows `bodyA` when `bodyA` is in the pose (it keeps its rest position relative to `bodyA`), else stays at rest. Missing body and root positions are (0, 0), like `js/viewport/placement.js`; a joint anchor that is missing or not a finite pair contributes nothing (#12 rule shared with placement). Shapes whose `shapeBounds` throws or is non-finite are skipped, so drafts and invalid files still frame. | `framingBounds(model, uids \| null, pose?) → Aabb \| null` (`null` only when the given uids contribute nothing), `FRAME_MIN_SIZE` (1 m), `FRAME_EMPTY_SIZE` (4 m), `FRAME_MARGIN` (16 px), `framingInsets(overlayWidth = 0) → Insets` (throws `RangeError` for a width that is not finite or is negative), typedef `Pose` (`Map<bodyUid, Transform>`, root-local) | `lib/geometry.js`, `js/model/model.js` |
| `js/viewport/placement.js` | Core. World placement of the displayed pose, shared by hit testing, gizmos and tools ([`DESIGN.md` §5.4](../design/05-4-viewport.md#54-viewport)): root transform, body world transforms (pose, else rest), joint anchors following `bodyA` (same rule as `js/viewport/bounds.js`), joint zero directions and current angles. A missing body or root `position` is (0, 0) and a missing `angle` 0; a joint `anchor` that is missing or not a finite pair is not placed: its entry in `anchors` is non-finite (NaN), its `zero` is `null` and its angle 0. `zero` is also `null` without a valid `bodyA` and `bodyB`. | `placement(model, pose?) → Placement`, `jointZeroAngle(anchor, bodyBTransform) → number` (rest-pose zero direction in the frame of its arguments: anchor → bodyB origin, or bodyB's angle when they are within 1e-9 m; also used by the Hinge tool before a joint exists), typedef `Placement` (`root: Transform`, `bodies: Map<uid, Transform>`, `anchors: Map<jointUid, Vec2>`, `zero: Map<jointUid, number \| null>`, `angles: Map<jointUid, number>`; world meters and radians) | `lib/geometry.js`, `js/model/model.js` (`ROOT_UID`) |
| `js/viewport/hit.js` | Core. Hit testing ([`DESIGN.md` §5.4](../design/05-4-viewport.md#54-viewport)) at a screen point under the displayed pose: joints within `HIT_RADIUS.joint` of their anchor (reverse `joints` order), the root within `HIT_RADIUS.root`, then shapes through `pointInShape` with `HIT_RADIUS.shape / camera.scale` m of tolerance (reverse body order, reverse fixture order). Returns every hit, topmost first; skips invalid geometry and joints whose anchor is not placed. | `hitTest(model, camera, screen, { pose } = {}) → number[]` (uids of type `joint`, `root`, `shape`), `boxTest(model, box, { pose } = {}) → number[]` (uids of the shapes entirely inside a world box and of the joints whose anchor is inside it, never the root; skips invalid geometry and unplaced anchors) | `lib/geometry.js`, `js/model/model.js` (`ROOT_UID`), `js/viewport/placement.js`, `js/viewport/style.js` |
| `js/viewport/style.js` | Core. Viewport drawing and hit constants shared by core and UI ([`DESIGN.md` §5.4](../design/05-4-viewport.md#54-viewport)), all frozen: colors as integers (`highlight` 0x5b9cf5, `invalid` 0xe5484d, `shapeOutline` 0xf08a24 (the base shape outline, drawn by `js/viewport/scene.js`), `gizmo` 0xd8dade, and the transform gizmo `gizmoX` 0xe0524f, `gizmoY` 0x58b85c, `gizmoZ` 0x3d6dff (the dashed rotation ring), `gizmoFree` 0xf2c94c, `handleOutline` 0x1b1d21 (outline of resize handles)), line widths (`outline` 1, `selected` 2, `gizmo` 2 CSS px), gizmo sizes (`rootCross` 14, `rootRing` 10, `jointCircle` 6, `jointArc` 20, `jointNeedle` 20, `aimArrow` 32, `centerOfMass` 5 px, and the transform gizmo sizes `arrowStart` 16, `arrowTip` 56, `arrowHead` 10, `arrowWidth` 8, `squareOffset` 16, `squareSize` 12, `rotateRing` 72, `pivot` 4, `resizeHandle` 8, `resizeHandleActive` 10), hit radii (`joint` 8, `root` 12, `shape` 4, `handle` 8, `gizmo` 6 px), label size 11 px. | `COLORS`, `LINE_WIDTH`, `GIZMO_SIZE`, `HIT_RADIUS`, `LABEL_SIZE` | — |
| `js/viewport/grid-lines.js` | Core. Grid geometry ([`DESIGN.md` §5.4](../design/05-4-viewport.md#54-viewport)): spacing levels, the fine and coarse level for a scale, fine-level opacity, visible line positions in screen px, axes. Fine lines are omitted when their opacity is 0 and where they fall on coarse lines; lines at world 0 are kept, and `js/viewport/grid.js` draws the axes on top of them. | `gridLevels(scale, size, subdivisions) → { fine: { spacing, alpha }, coarse: { spacing } }`, `gridLines(camera, { size, subdivisions }) → GridLines`, typedefs `GridLine` (`orientation: 'vertical' \| 'horizontal'`, `world`, `screen`, `level: 'fine' \| 'coarse'`, `alpha`), `GridLines` (`lines: GridLine[]`, `axes: { vertical: number \| null, horizontal: number \| null }`, screen px) | — |
| `js/viewport/snap.js` | Core. Snapping rules ([`DESIGN.md` §5.4](../design/05-4-viewport.md#54-viewport)): grid snap to the minor spacing in world coordinates when `snap.grid` is on, circle radius rounding, SHIFT angle snap to 15°. Bound to `editor.settings` as `ToolContext.snapPoint`, `snapLength` and `snapAngle`; the Circle and Box tools use `snapPoint` and `snapLength`, the Hinge tool uses `snapPoint` and `snapAngle`, and the Select transform uses `snapPoint` and `snapAngle`. | `snapPoint(p, settings) → Vec2`, `snapLength(length, settings)`, `snapAngle(angle, shift)`, `ANGLE_SNAP` (π/12); `settings` is a `Settings` instance, read with `get` | — |
